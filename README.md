# sql-projects
Анализ транзакций клиентов · SQL (MySQL)
Задача

По транзакциям магазина за 13 месяцев (июнь 2015 – июнь 2016) найти постоянных клиентов и описать покупательское поведение в разрезе месяцев, пола и возраста.

Данные

Две таблицы: клиенты (пол, возраст) и транзакции (дата, чек, клиент, количество, сумма). Загрузка из CSV через LOAD DATA INFILE.

Что сделано
Подготовка данных: пустые значения пола и возраста приведены к NULL, таблица транзакций создана с нужными типами.
Клиенты с непрерывной историей: покупки в каждом из 13 месяцев. Для них посчитаны средний чек, средняя сумма в месяц и число операций.
Помесячные показатели: средний чек, операций на клиента, число активных клиентов, доля месяца в годовой выручке и операциях.
Структура по полу (M / F / нет данных) по месяцам и доля затрат каждой группы.
Возрастные группы с шагом 10 лет и отдельной группой «нет данных»: за весь период и поквартально, средние показатели и доли.
Приёмы SQL

CTE (WITH), JOIN / LEFT JOIN, агрегаты с HAVING, оконные функции (SUM() OVER ()) для расчёта долей, CASE для сегментации, COALESCE / NULLIF для работы с пропусками.
